# BLK_MAJESTY storefront

Static black-and-white shapewear storefront (theme draft — no checkout or payments).

- `index.html` — home page (hero, collection, contact)
- `product.html` — High-Waist Shaping Briefs product page (gallery, bundle picker, reviews, FAQ)
- `styles.css` / `main.js` — shared styles and behavior (demo bag, dialogs, bundle picker)
- `sections/blk-majesty-storefront.liquid` — the separate Shopify section uploaded earlier

Open `index.html` in a browser, or serve the folder: `python3 -m http.server`.
